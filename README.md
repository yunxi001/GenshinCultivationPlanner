# 养成材料调度器（开发版）

## 快速使用

1. 在 BetterGI 调度器中添加本脚本，并打开“修改 JS 脚本自定义配置”。
2. 在“培养目标”填写目标。例如：

   ```text
   申鹤:70>90,6/8/8>9/9/9；和璞鸢:70>90
   ```

   角色格式为 `名称:当前等级>目标等级,普攻/战技/爆发当前>目标`；武器格式为 `名称:当前等级>目标等级`。支持中文和英文标点、全角数字及换行。
   当前等级若正好为 20/40/50/60/70/80，按“该档尚未突破”计算；例如 `提纳里:80>90` 会包含最后一档月莲与首领材料。
3. 首次运行保持“仅生成计划”开启，核对日志、背包识别与邮件摘要。
4. 确认无误后取消“仅生成计划”，填写秘境队伍名称，再运行。脚本会切队、传送七天神像恢复并消耗已有浓缩树脂后再消耗原粹树脂；不会合成树脂。

## 当前已实现

- 角色、武器的材料计算；输入错误会在执行前拦截。
- 自动读取有关背包材料，并按 3:1 合成链计算缺口。
- 周日按材料开放日自动选择奖励组。
- 已映射 14 个 BetterGI 培养材料秘境，覆盖蒙德至挪德卡莱的天赋书与武器突破材料；太山府「繁荣」已实机执行，其他映射依据 BetterGI 内置奖励表生成，待集中实机回归。
- 运行摘要通知、运行记录和执行前后背包复核。
- 已映射周本与世界 Boss：周本优先、Boss 次之，均仅使用原粹树脂；未匹配到 BetterGI 内置首领的材料会保留为人工待办。
- 可选圣遗物秘境填充：仅当天没有培养树脂任务时执行，独立配置秘境、队伍和策略，默认不分解圣遗物。

## 当前限制

- 周本、已映射世界 Boss 与已匹配地方特产/怪物路线可执行；所有自动映射均须先在“仅生成计划”模式核对，再进行实机回归。
- 地方特产/怪物路线从 `User/AutoPathing` 执行，继承自动培养调度器配置组的地图追踪与自动战斗参数；脚本会像原生 `Pathing` 项目一样在路线开始前启用 BetterGI 自动拾取。
- 队伍名称必须能被 BetterGI 正确匹配；同一队伍连续切换失败两次后会在本次运行中标记为不可用，跳过其余相关路线并继续保存报告，不会对每条路径重复传送和切队。
- 除首批映射外，其他秘境尚待集中实机回归；实测失败时会在对应测试分支修正映射。
- BetterGI 目前在实机中未稳定识别秘境奖励，收益统计应以背包实际数量为准。
