# 养成材料调度器

根据角色、天赋和武器目标读取背包，计算实际材料缺口，并调用 BetterGI 完成当天可执行的刷取任务。脚本只负责材料计算与调度，不会在游戏内升级角色或武器。

## 快速使用

1. 在 BetterGI 脚本仓库订阅并添加“养成材料调度器”。
2. 选择角色、角色等级、三项天赋区间以及可选武器；需要多个目标时启用“自定义培养目标”。
3. 填写会实际使用的队伍名称。队伍名必须和游戏内完全一致。
4. 首次运行建议将培养秘境设为“单次测试”，Boss、地方特产路线和怪物路线保持关闭。
5. 核对设置后，勾选“我已确认配置并允许实际执行”，再运行脚本。未勾选时脚本会立即终止，不读取背包或操作游戏。
6. 单次测试正常后，再按需启用正式秘境、Boss 或路线。

自定义目标示例：

```text
申鹤:70>90,6/8/8>9/9/9；和璞鸢:70>90
```

支持中文/英文分号、逗号、冒号和换行。启用自定义目标后，上方角色、武器、等级及天赋选择全部失效。

## 当前功能

- 合并角色等级、三项天赋及武器等级所需材料，并扣除背包库存。
- 按 3:1 合成链折算天赋书、武器突破材料和怪物材料，缺口仍按高、中、低阶分别显示。
- 自动选择当天开放且仍有缺口的培养材料秘境，周日按材料系列选择第 1、2 或 3 项奖励。
- 可选执行已映射的世界 Boss；Boss 默认关闭，建议先单次测试特殊机制与队伍。
- 自动发现 BetterGI 已订阅的地方特产及怪物材料路线；两类路线可独立启用。
- 当天没有可执行培养树脂任务时，可选用指定圣遗物秘境填充树脂。
- 保存最新计划和最多 100 条历史记录，并可通过 BetterGI 的 JS 通知渠道发送 HTML 摘要。
- 生成从当天开始的七天循环策略及培养秘境/Boss 预计领奖次数和树脂需求。

## 执行规则

树脂任务顺序固定为：世界 Boss → 当天限时培养秘境 → 普通培养秘境 → 圣遗物填充。一次运行只执行首个已启用且可执行的树脂任务；随后再执行已启用的地方特产和怪物路线。

培养与圣遗物秘境默认按“浓缩树脂 → 原粹树脂”使用已有树脂，也可显式允许须臾树脂或脆弱树脂。脚本不会合成浓缩树脂。Boss 只使用原粹树脂。

整次运行只在任务开始前和全部任务结束后读取背包，收益以两次库存差值为准，不在每次领奖或每条路线后重复打开背包。

周本材料会参与需求计算，并在日志和邮件中标为“需手动获取”；0.9.0 不自动执行周本，也不会让周本缺口阻塞其他任务。

## 路线要求

脚本不会内置或下载 AutoPathing 路线。请先在 BetterGI 中订阅对应路线，常见目录结构如下：

```text
地方特产/国家/材料名/**/*.json
敌人与魔物/怪物名/**/*.json
```

自动匹配失败时，可编辑 `data/route-overrides.json` 指定路线。蕈兽孢子路线请避免使用火、雷攻击导致掉落变化。

<details>
<summary>限制与注意事项</summary>

- 不刷摩拉、经验书或元素突破玉，也不执行材料合成。
- 正式秘境会尽量用完所选树脂，不会在材料刚好满足时中途停下，可能少量多刷。
- 不同 Boss、秘境和路线的稳定性取决于 BetterGI、游戏版本、队伍和用户订阅内容；特殊机制应先单次测试。
- OCR 可能失败。未确认到背包增长时，摘要只报告“未确认”，不会把任务调用等同于成功领奖。
- 圣遗物填充不自动分解圣遗物，其收益也不计入培养材料差值。
- 首次切换任务队伍前会传送七天神像；后续切队失败时只传送并重试一次，避免错误队伍名造成循环。
