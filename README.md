# 角色一键养成

「角色一键养成」把原神角色培养中最费心的几步串成了一次运行：读取角色现状、计算材料、核对背包、安排刷取、执行任务，再把结果发到邮箱。

默认用法是在脚本设置中选择角色、目标等级和三项天赋；需要培养武器时，再选择当前佩戴武器或指定武器。也可以勾选“附加提升指南培养计划（默认关闭）”，把游戏内**提升指南**中尚未出现在原计划里的角色和武器追加进来。

日常使用不需要手写材料清单，也不用自己查询角色该打哪个 Boss、哪个秘境或星期几开放。脚本会自动推导所需材料和数量，扣除背包库存与可合成数量，并把当天能做的任务交给 BetterGI。

每次运行后，邮件会清楚列出本次刷了什么、确认获得多少、还缺什么以及大约还要刷多久。即使不守着电脑、不翻日志，也能了解培养进度。

> 这里的“一键”是从培养目标到材料刷取和进度统计的一站式流程。脚本不会在游戏中点击升级角色或武器。

## 核心流程

1. 选择角色和培养目标。
2. 自动读取当前角色等级、天赋和武器状态。
3. 自动计算角色、天赋和武器所需材料。
4. 读取背包，按 3:1 合成关系扣除已有材料。
5. 自动匹配世界 Boss、培养秘境、开放日和已订阅路线。
6. 按规则执行当天任务，并在结束后复核背包。
7. 通过邮件汇报本次收益、剩余缺口和预计进度。

队伍和可选路线完成一次基础配置后，更换角色或培养目标即可重新计算，不需要重新整理材料表。

## 主要功能

- 支持角色等级、普通攻击、元素战技、元素爆发和武器等级目标。
- 可选择“角色和当前武器”“角色和指定武器”“仅角色”或“仅指定武器”。一星初始武器会自动忽略。
- 自动处理天赋书、武器突破材料和怪物材料的 3:1 合成链，并按各个等级显示实际缺口。
- 根据材料自动匹配世界 Boss 和培养秘境，周日自动选择正确的奖励系列。
- 生成从今天开始的七天循环策略，限时开放的培养秘境优先安排。
- 可执行世界 Boss、培养秘境、地方特产路线、怪物材料路线，以及可选的圣遗物秘境填充。
- 整次运行只在开始和结束时读取背包；背包差值可信时优先采用，漏识别时使用 BetterGI 的任务奖励兜底，避免重复统计。
- 保存最近 100 次运行记录，并可通过 BetterGI 通知发送排版后的培养摘要。

## 使用前准备

- BetterGI `0.64.0` 或更高版本。
- 在 BetterGI 中启用 OCR V6。
- 准备好用于秘境、Boss 和路线的游戏队伍，队伍名称必须与游戏内一致。
- 如需采集地方特产或怪物材料，先订阅相应的 AutoPathing 路线。
- 如需关键进度与运行摘要，请在 BetterGI 通知设置中启用 JS 通知，允许本项目发送通知，并配置 Telegram、邮件等原生通知渠道；如果设置了事件订阅，需包含 `js.custom`。启用“通知附带截图”后，BetterGI 会为通知附加当前游戏画面。

角色、武器或数量文字识别异常时，请先确认 OCR V6 已启用。背包物品名称由 BetterGI ItemV2 图标模型识别；脚本会把“图标未匹配”和“数量 OCR 失败”分别记录。

## 快速开始

> **使用提升指南：** 开启指南后，无需手动填写角色、等级、天赋和武器培养目标，保留角色与武器的“未选择”状态即可。详见[附加提升指南目标（可选）](#附加提升指南目标可选)。

1. 在 BetterGI 脚本仓库中订阅“角色一键养成”，并加入调度器或一条龙。
2. 选择“读取档案并执行”和要培养的内容。
3. 选择角色、目标等级和三项天赋；指定武器模式还需选择武器及等级区间。
4. 填写培养秘境队伍。Boss、路线和圣遗物填充默认关闭，需要时再启用。
5. 检查设置并勾选顶部的“允许实际执行”，然后运行。

未勾选执行确认时，脚本不会读取背包、写入记录、发送通知或操作游戏。

如果加入 BetterGI 一条龙，请勿在脚本后面重复启用内置“自动秘境”或“自动首领讨伐”，否则可能继续消耗树脂，也会干扰结果判断。

## 培养目标与等级

脚本会通过 BetterGI 读取所选角色的当前等级、突破状态和天赋等级。目标等级和三项天赋仍由用户选择，脚本不会自行决定培养到多少级。

自动档案或提升指南读取到已达 95／100 级的角色时，保留实际等级记录，并按等级培养已完成的 90/90 状态规划天赋和武器。消耗特殊道具提升至 95／100 级不属于脚本的培养范围。

若这些角色的档案等级上限读数异常，只有提升指南明确确认等级培养已完成、且两处实际等级一致时，才依据指南继续规划；原始读数和采用依据会保留。

培养内容有四种：

- **角色和当前武器**：读取角色档案，并培养当前佩戴的非一星武器。
- **角色和指定武器**：角色状态自动读取，武器由用户选择。
- **仅角色**：只计算角色等级和所选天赋。
- **仅指定武器**：不读取角色档案，只处理选择的武器。

等级没有明确标注“已突破”时，默认按突破前计算。某个目标已经达到要求或识别失败时，只跳过该项目，不影响其他可以独立计算的目标。

“预览目标”仅用于排查：它会保存识别结果，但不读取背包、不刷取材料，也不发送进度、失败或运行摘要；首次使用不需要先预览。

## 附加提升指南目标（可选）

“附加提升指南培养计划（默认关闭）”勾选后，脚本先按原有设置生成计划，再读取提升指南中已启用的角色，以及角色、武器和天赋的期望等级。两边存在同类型、同名称目标时保留原计划，指南目标不会合并、修改或覆盖它；其余指南目标追加到计划中，并统一沿用原有调度逻辑。

指南目标会通过 BetterGI 角色档案核对当前等级、突破状态和天赋加成。原计划已经完整读取过同一角色的角色、武器和天赋档案时会直接复用；原计划只读取了部分字段时，指南会另行读取完整档案，且读取失败不会破坏有效的原计划。脚本据此计算完整的突破、天赋、特产和怪物材料需求，再交给现有的背包读取、计划、路线、树脂任务和执行流程，不使用另一套执行器。

使用服务器日期时，指南可提供本次识别到的武器或天赋材料“限时开放”证据。GCP 将证据匹配到精确秘境和奖励系列，再通过统一的开放覆盖入口修正本次计划：手动、预刷和指南目标共用，指南目标被同名原计划跳过也不丢弃对应开放证据。没有确认的材料仍按正常星期安排；不会扩大为所有秘境全开、启用手动材料、保存到后续运行或改变手动指定的计划日。记录中的 `domainOpenings` 保留实际采用的依据。当前尚不独立读取冒险之证；以后增加读取来源可复用同一入口，不需修改指南 OCR 或另写调度器。

如果只想使用提升指南，可以保留角色和武器的默认“未选择”状态并勾选该选项，不需要填写占位角色。若已经填写原计划但配置无效，脚本仍会按原有规则报错，不会用指南掩盖配置问题。

选择原有“预览目标（不执行）”并勾选提升指南时，脚本先生成组合计划并保存 `record/latest-guide.json`，随后在读取背包和执行任务前返回；确认要求与原有预览相同。指南中身份、档案映射或材料成本不支持的角色会记录警告并跳过，其他有效角色与原计划继续处理；纯指南全部角色不可用时停止，空指南和有效的已完成目标不视为失败。整份指南读取失败时，已有的有效原计划仍会继续执行并记录警告；纯指南计划停止。档案接口或记录写入失败仍会停止本次运行。指南中的圣遗物推荐不会改动“圣遗物填充”设置。

## 未拥有角色预刷（可选）

仍使用上面的角色、等级、天赋和武器设置，只需勾选默认关闭的“允许预刷”。不需要额外目标文件，也不切换运行模式。多名角色沿用 BetterGI 调度组中的多条脚本配置，每条选择一名角色。

脚本每次先读真实档案。首次收到精确的同名“未找到角色”或角色名称元数据校验失败提示时，开启预刷才按角色 `1/20`、天赋 `1/1/1` 计算；这是假设初始进度，不是伪造真实档案。普通 OCR/接口错误不触发初始值。以后成功读取角色，会直接使用真实等级、突破状态和还原命座加成后的天赋，目标值不变，预刷开关也不用关闭。成功实读会保存在 `record/prefarm-observed.json`；此后读取失败不再倒退成1级，记录损坏或写入失败会停止执行。

未拥有角色没有“当前佩戴武器”。需要提前刷武器时，选择现有的“培养角色和指定武器”，填写武器和等级区间；指定武器保持原有独立语义，不随角色装备改变。如果选择“当前佩戴武器”，未读到真实档案时仅跳过武器，不阻塞可计算的角色目标。

背包扫描正常完成但没找到的材料按0计算，模型尚不认识的新材料也一样；数量 OCR 明确失败或整页扫描失败仍按原有异常规则处理。历史最近一次确认数量为正、本次却未找到时，脚本会提示可能重复获取，但仍按0继续计算和刷取，避免一次识别冲突导致后续运行永久停摆。结束复核继续保留原来的奖励校验，不把漏识别伪造成零收益。

角色、武器成本、材料和来源都在正常数据文件中维护，没有另一套预发行数据库。只有标记为 `supported`、具备完整映射且配置启用的任务才会安排执行；`manual` 不因开启预刷而改变，未实装或未确认支持的 Boss 待确认后再显式更新数据状态。

对于已进入执行队列的任务，开启预刷时，原生接口精确返回该 Boss 不支持或该秘境没有传送点，才会跳过本轮并替补其他候选。替补不会增加原有领奖预算；取消、战斗失败、无法确认领奖等情况不会当成“未支持”继续刷。周本仍按原脚本政策手动处理。

## 自动匹配与任务执行

世界 Boss 会根据缺少的突破材料自动匹配，用户不需要输入 Boss 名称。通常填写通用 Boss 队伍即可；机制特殊的 Boss 可以使用专属配置，例如：

```text
急冻树:队伍=火队,策略=急冻树策略；无相之水:禁用
```

多个 Boss 使用中文或英文分号分隔。队伍或策略留空时继承通用配置；`禁用`表示这个 Boss 不自动执行，脚本会继续寻找其他当天任务。Boss 名称会在操作游戏前校验；允许预刷时也接受材料数据中明确映射的世界 Boss 名称。

战斗策略留空时，培养秘境和圣遗物秘境继承 BetterGI 全局“自动战斗”设置，世界 Boss 继承“自动首领”设置。只有特殊队伍确实需要独立策略时才需要填写。

第一次切换任务队伍前，脚本会先传送到七天神像；切换失败时只传送并重试一次，避免错误队伍名造成循环。Boss 任务结束后还会统一尝试安全退场，不会在每轮领奖后反复传送。

## 树脂与调度规则

推荐模式按以下顺序寻找任务，并执行第一个可用类别：

```text
世界 Boss → 当天限时培养秘境 → 普通培养秘境 → 圣遗物填充
```

高级模式可以按顺序执行多个类别，并分别设置领奖次数。“用完可用树脂”表示把当前可用预算全部交给这一类任务，后续树脂任务不再尝试。任务失败、奖励未确认或 BetterGI 明确报告树脂不足时，也会停止后续任务。

培养秘境默认先使用已有浓缩树脂，再使用原粹树脂；脚本不会制作浓缩树脂。世界 Boss 只使用原粹树脂。当前版本不在多个同类秘境之间做精确树脂分配，因此一次运行可能比当前缺口多获得少量材料。

圣遗物填充默认关闭。启用后可在没有培养材料任务时使用剩余树脂；圣遗物不会计入培养材料收益或预计完成时间，也不会自动分解。

## 背包、合成与进度通知

材料计算只采用确定的基础配方，例如 3 个低阶材料合成 1 个高一阶材料。行秋、优菈等角色天赋带来的概率返还或额外产出不会提前计算；实际获得的额外材料会在后续背包读取中体现。

如果结束背包漏识别，但 BetterGI 已识别到任务奖励，脚本会用任务奖励补充确认，不与背包差值重复相加。如果同一培养目标的历史记录确认有某项材料、下一次背包却完全找不到，脚本会在摘要中提示风险，并按当前未找到（0 个）继续计算和刷取；这可能导致重复获取。材料已经用于升级时，请及时更新当前等级。

启用“发送关键进度与运行摘要”后，正式运行会在开始、执行计划就绪和结束时发送通知；未处理异常会发送失败摘要。计划就绪通知会列出角色与天赋目标以及待执行任务；其中的任务数和领奖上限只是计划，不代表已经领奖或已经消耗树脂。运行摘要包括：

- 当前培养目标和识别到的进度。
- 本次执行的 Boss、秘境或路线。
- 本次确认获得的目标材料。
- 背包识别或任务执行警告。
- 仍缺材料和需要手动获取的周本材料。
- 预计领奖次数、树脂和完成时间。

## 地方特产与怪物路线

脚本不附带路线，也不会自行联网下载。请先在 BetterGI 中订阅路线，常见目录为：

```text
地方特产/国家/材料名/**/*.json
敌人与魔物/怪物名/**/*.json
```

脚本会按材料名称和常见别名自动查找；未匹配到时，可以在 `data/route-overrides.json` 中指定路径。刷取蕈兽孢子时请使用不包含火、雷攻击的队伍，否则掉落类型会改变。

## 当前边界

- 不执行角色或武器升级。
- 不自动刷摩拉、经验书和元素突破玉，也不在游戏中合成材料。
- 周本材料会计算并提醒，但当前版本不自动打周本。
- Boss、路线和圣遗物填充默认关闭，实际稳定性取决于 BetterGI、游戏队伍和订阅路线质量。
- 7.1 新角色沃雅妮莎、薇斯纳已可计算培养材料；两人的新突破 Boss 暂列为手动获取。秘境按开放日规划，地方特产和怪物材料在订阅对应路线后可自动匹配。
- 背包和任务奖励都无法确认收益时，摘要会标记“未确认”，不会把任务调用误写成成功领奖。
- 脚本不申请 HTTP 权限，运行时不依赖 npm 或网络服务。

## 更新开发期数据

更新 `genshin-db` 的精确版本和锁文件后，沿用 `tools/` 中的生成工具：

```bash
pnpm install --frozen-lockfile
pnpm exec node tools/build-rulebook.mjs
pnpm run build:guide-identities
```

`build-rulebook.mjs` 生成培养成本、材料、合成配方和来源候选，并调用 `update-target-selectors.mjs` 同步角色／武器下拉选项。

`build-guide-identities.mjs` 生成提升指南读取所用的 `guide-reader/data/guide-identities.json`，只包含角色技能名称与槽位、武器身份及数据版本。同名武器保留全部候选，旅行者元素歧义保留为未确定；数据校验失败时不会覆盖已有文件。

新材料有来源数据不代表原生接口已支持自动执行。已核对的秘境使用精确名称、开放日及奖励序号；未实装或尚未确认 BetterGI 支持的世界 Boss 保持 `manual`，即使开启预刷也不调用。保留来源映射，待确认支持后再显式更新为 `supported`。周本仍手动获取，采集仍依赖已订阅路线。这些生成工具仅供开发使用，BetterGI 运行时不需要 Node.js。

### 7.1 角色数据

沃雅妮莎、薇斯纳及同期武器现由 `genshin-db 5.2.14` 正式数据生成。尚未拥有角色时仍可使用“允许预刷”，自行设定目标等级和天赋；两位角色的突破 Boss 当前只提醒手动获取。上游此次也把星锋剑的突破消耗改为零，脚本按该版本原始数据计算。
